## The problem

People carry operational knowledge in their heads, and manual handover documents take time and go out of date.

## What it does

Ten modules rebuild the workflow from the task data, find knowledge gaps and ask the task owner to clarify them. After approval, the system produces handover materials. It marks each step as observed or confirmed, so that a reader can see the source of the step. A practice mode lets the covering colleague test the handover.

## Current status

This version uses rule-based JavaScript modules and does not call an AI model. The repository includes a fictional demonstration scenario. It has not been evaluated with real teams.
